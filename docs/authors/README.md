# Author Profiles — IRE Knowledge Identity Layer
#
# Each team member who wants AI tools to draft documents in their voice
# creates one file here:  docs/authors/{username}.md
#
# Steps:
# 1. Copy `_template.md` to a file named after your Intel username
#    Example:  docs/authors/jmonroe.md
# 2. Fill in every field — don't leave placeholders
# 3. Add your entry to docs/ire-knowledge-schema.yaml under `authors:`
# 4. Commit — AI tools will use your profile from that point forward
#
# ─────────────────────────────────────────────────────────────────────────────
#
# PRIVACY NOTE: Author profiles are committed to the project repo and will be
# read by AI tools in every session. Do not include personal contact info,
# home addresses, or anything beyond professional writing context.
#
# ─────────────────────────────────────────────────────────────────────────────
