## Activity by Project

### jhu / intel-analyze-wifi
*WiFi Analyzer — PowerShell → C# Standalone Executable*

**Win #13 — Excel Feature Comparison Tool (PowerShell)**

A fully standalone Windows PowerShell application that loads 2 or more Excel specification files,
auto-detects relevant columns using synonym matching, and produces a side-by-side model comparison
with difference highlighting. No Python, no venv, no dependencies beyond a single auto-installing
PowerShell module (ImportExcel).

**Key PS1 files delivered**
- `intel-analyze-wifi.ps1` — single-file Windows Forms app (GUI + loader + comparator + export)
- `setup.bat` — one-click installer: creates `C:\temp\wifi`, installs ImportExcel, copies files
- `run.bat` — launches app via `powershell -ExecutionPolicy Bypass` (or exe if present)
- `demo\demo_intel_wifi7_series.xlsx` — 5 publicly available Intel Wi-Fi 7 adapter specs
- `demo\demo_intel_killer_series.xlsx` — 9 publicly available Intel Killer series adapter specs
- `demo\demo_qualcomm_fastconnect.xlsx` — 4 publicly available Qualcomm FastConnect adapter specs

**Stack:** PowerShell 5.1 · Windows Forms · ImportExcel module · DataGridView

---

**Win #14 — First C# Program: WiFi Analyzer Standalone Exe**

The PowerShell app was rewritten as a fully standalone compiled Windows executable — the first
C# program ever written, with zero prior C# training or coursework. Single double-clickable `.exe`,
54 KB, no installer, no module dependencies, no PowerShell required. Runs natively on any modern
Windows machine using .NET Framework (which ships with Windows).

**Key C# deliverables**
- `WifiAnalyzer.cs` — single C# source file (~700 lines)
- `WifiAnalyzer.exe` — compiled standalone executable (54 KB)
- `build.bat` — compiles with `csc.exe` (ships inside Windows — no Visual Studio needed)

**C# App Features**
- **Tab 1 — Spec Comparison:** full port of PS1 app: add xlsx files, compare, highlight diffs, export
- **Tab 2 — Throughput Analysis:** load device measurement CSVs, ranked DataGridView, line chart, rankings
- XLSX read/write via `ZipFile` + `XmlDocument` — zero NuGet packages, zero external dependencies
- Custom `ThroughputChart` GDI+ panel — line graph with legend, axes, data points, no charting library
- Rankings: best peak, best range, best average, best signal retention across all loaded devices
- All file dialogs default to `C:\temp\wifi` — no network path exposure

**Stack:** C# 5 · .NET Framework 4.5 · Windows Forms · DataGridView · GDI+ · ZipFile · XmlDocument · csc.exe
