KEY TECHNICAL NOTES
-------------------
- Power Automate Direct API URLs cannot be called from external scripts in
  Intel's tenant (corporate policy). Graph API is the correct approach.
- SharePoint Online does not support Windows Integrated Auth from scripts.
- PnP.PowerShell requires PS 7.4+; system runs PS 5.1. Use Graph API instead.
- Teams notebooks (SharePoint-hosted) require Notes.ReadWrite.All scope.
  Personal OneDrive notebooks only require Notes.ReadWrite.
- OneNote app-only (service account) auth is blocked by Microsoft --
  device code flow with a real user account is the only supported headless method.
- SharePoint people fields use integer lookup IDs, not email addresses:
    Monroe, John = ID 13  (in IRE Project Tracking list)
